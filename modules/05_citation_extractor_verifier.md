# Module 5: Citation Extractor and Verifier

Purpose: Extract and verify citations in the text.

Step-by-Step Instructions:
1. Extract all citations exactly as they appear in the source text.
2. Detect missing or malformed citations.
3. Ensure no citations are invented.
4. Include a citation audit in the Checks & Warnings output.
5. Flag any inconsistencies between in-text citations and reference list if available.
